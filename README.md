# Ludo Powers
A browser-playable local multiplayer Ludo prototype.

## Run
Open `index.html` in a modern web browser.

## Included
- 2–4 local players
- Dice and turns
- Four pieces per player
- Basic Ludo movement/capture
- Power collection
- Teleport, Shield, Extra Roll, Attack, Freeze, Invisible, Pull, Double Move
- Main menu, game UI, game log and victory screen

This is a prototype. Online multiplayer, accounts, matchmaking, sound, persistence and production-grade rules can be added next.
